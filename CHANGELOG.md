# Changelog

## 0.1.1

- Flutter demo migrated to `material_ui`/`cupertino_ui` (Flutter 3.47+).
- CI validates the demo on Flutter 3.50.1. No package API changes.

## 0.1.0

- Offline 2026/2027 MOPA data with sources and uncertainty.
- General, executive, optional and district-specific applicability.
- Day/month/year/range/next queries preserving overlapping occurrences.
- Configurable office calendars, count/add working days and daily explanations.
- Approved optional dates, company closures, occurrence overrides, official
  office-opening orders and unsupported-year errors.
- Strict JSON validation and deterministic generated Dart data.
- Documented public APIs and repeatable package verification, including extreme
  counts and coverage boundaries.
- English/Bangla mobile Flutter demo: Calendar, Calculate and Rules.
