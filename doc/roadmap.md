# Roadmap

The roadmap is a direction for future work, not a delivery schedule.

## v0.1.0

Official-source 2026/2027 data, business-day calculations and explanations,
district/optional/company rules, source and uncertainty metadata, overrides,
coverage errors, bilingual mobile Flutter demo, docs and maintenance workflow.

## v0.2

Bangabda conversion following Bangladesh's calendar rules, documented boundaries
and manual leap-year/date-transition checks. Refine APIs using real integrations.

## v0.3

A local stdio MCP server using this package. Expose coverage, sources and
uncertain dates rather than inventing unavailable answers.

## v1.0

Stabilize APIs after usage feedback, keep source updates current, and document
compatibility and release policy.

## Later, if useful

Bangladesh Bank calendars, ICS export, older datasets and more granular
regional/sector policies.
